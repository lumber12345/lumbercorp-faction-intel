About these numbers & API privacy

These are current faction members’ lifetime personal stats, including activity before joining the faction. They are not faction-period totals or live overdose alerts. Daily and weekly OD counts subtract historical overdose totals requested approximately 1 and 7 days before sync from current lifetime totals. Torn converts historical queries to the nearest date: these are approximate periods, not exact rolling 24-hour or 168-hour windows. Missing historical values display — and are excluded from period totals; each card shows coverage. Weekly includes daily counts. Weekly booster and consumable counts use the same approximate historical comparison. Boosters, energy drinks, candy, and alcohol are displayed as separate Torn API categories, not added together; these public counts do not identify individual item names. Missing booster history displays —, not zero. Historical calls use five requests per member overall, so syncing a large faction can take several minutes. OD rate is total overdoses divided by total drugs used; it is not a Xanax-specific rate. Missing stats are excluded from totals, never counted as zero.

A public-access Torn API key is sufficient. The key is kept only in this tab’s memory, is never saved to storage, and is sent directly to api.torn.com in an authorization header. Requests are paced at approximately 50 per minute; other tools sharing your key or IP may still cause rate limits. No automatic background refresh. Refresh to update daily and weekly counts.
